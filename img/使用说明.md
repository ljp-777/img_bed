# 智慧大脑后台页面自动截图流程使用说明


## 一、用途说明

本流程用于 **智慧大脑后台系统** 的页面自动化截图，实现：

* 自动登录智慧大脑后台
* 按配置好的页面列表依次访问
* 对每个页面进行整页截图
* 按「时间 + 页面名称」自动保存到本地目录

主要适用于：

* 📸 页面留档 / 版本存证
* 🧪 测试回归对比
* 📊 前后端 / 产品联合验收
* 📄 项目阶段性资料留存

---

## 二、整体流程概览

整体逻辑如下：

```
1️⃣ 配置智慧大脑后台地址 & 页面列表
2️⃣ 打开浏览器并登录系统
3️⃣ 创建本次截图的时间目录
4️⃣ 进入智慧大脑首页
5️⃣ 循环访问每一个配置页面
6️⃣ 页面加载完成后截图
7️⃣ 保存截图到本地文件夹
```

## 四、核心配置说明

### 🔧 1. 智慧大脑后台地址配置

```text
baseUrl = http://172.16.100.206:9021
```

📌 说明：

* `baseUrl` 为 **智慧大脑后台系统地址**
* 切换环境（测试 / 预发 / 生产）时
  👉 **只需要修改这一行**

---

### 🔧 2. 页面配置列表（截图清单）

流程中通过一个 JSON 变量定义需要截图的页面列表：

```json
[
                {"page_name": "服务响应-诉求看板", "path": "/appealCenter/appealBoard"},
                {"page_name": "服务响应-服务资源调度", "path": "/appealCenter/serviceResources/powerSupplyStation"}, 
                {"page_name": "服务响应-停电抢修调度", "path": "/repair"},
                {"page_name": "服务响应-现场作业调度", "path": "/appealCenter/homeworkControlCenter}
]
```

📌 字段说明：

| 字段            | 含义                             |
| ----------------- | ---------------------------------- |
| `page_name` | 页面中文名称（用于截图文件命名） |
| `path`      | 智慧大脑后台页面路由             |

📌 实际访问地址为：

```text
jumpUrl = baseUrl + path
```

👉 **新增 / 删除截图页面，只需要维护这里**

## 五、流程详细说明

### 🟢 1. 打开浏览器并登录智慧大脑

* 使用影刀内置浏览器
* 自动访问：

```text
{baseUrl}/login
```

* 登录方式：
  * 手动登录一次
  * 或使用已保存的登录态（推荐）

---

### 🟢 2. 自动创建截图目录

目录示例：

```text
D:\
 └─ 智慧大脑截图
     └─ 202601221735
         ├─ 0_服务响应-诉求表板.png
         ├─ 1_用户管理.png
```

📌 规则说明：

* ​**一级目录**​：智慧大脑截图（固定）
* ​**二级目录**​：当前执行时间（yyyyMMddHHmm）
* ​**文件名**​：
  ```
  序号_页面名称.png
  ```

---

### 🟢 3. 初始化进入系统首页

流程会：

* 判断是否存在【搜索表单-用户】元素
* 若存在：
  * 点击【顶部-数据集成】菜单
* 确保智慧大脑系统处于正常可跳转状态

📌 目的：
避免页面未加载完成或菜单未初始化导致跳转失败。

---

### 🟢 4. 页面循环访问与截图

对 `navigationList` 执行 `ForEach` 循环：

每一轮流程：

1️⃣ 读取页面名称与路由
2️⃣ 拼接页面地址
3️⃣ 浏览器跳转页面
4️⃣ 等待页面渲染完成（默认 10 秒）
5️⃣ 获取页面 `body` 元素
6️⃣ 对当前页面进行整页截图

---

### 🟢 5. 页面截图说明

* 截图方式：网页截图（非屏幕截图）
* 截图范围：整个页面 body
* 支持长页面、表格、列表等完整截图
* 截图自动保存到当前时间目录
